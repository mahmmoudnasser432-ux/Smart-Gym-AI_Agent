1️⃣ Generate Plan API
----------------------------
POST /ai/generate-plan
----------------------------
Request

{
  "weight": 82,
  "height": 178,
  "age": 24,
  "gender": "male",

  "body_fat_pct": 21,
  "body_fat_mass": 17,
  "muscle_mass": 60,
  "smm": 32,

  "visceral_fat": 8,
  "bmr": 1750,
  "total_body_water": 45,

  "activity_level": "moderate",
  "training_frequency": 4,

  "disease": "none",
  "allergies": "none",

  "budget": "moderate",
  "language": "en"
}
---------------------
Backend يقوم بتشغيل:

full_agent()
--------------------
Response

{
  "goal": "fat_loss",

  "biological_age": 31,

  "calories": 2100,
  "protein": 160,
  "carbs": 200,
  "fat": 65,

  "plan_text": "...",

  "workout_days": 4
}
